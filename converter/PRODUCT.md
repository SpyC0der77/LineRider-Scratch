# Product

## Platform
web

## Purpose
Convert Line Rider track uploads and Scratch LR1 save codes into text accepted by the existing Scratch Line Rider project's Track > Load track code action.

## Constraints
Static client-only tool, no development server started. Preserve the existing project's sand, charcoal and muted green palette. User's supplied AGENTS instructions govern UI. Show unsupported behavior explicitly. Maximum 3,000 segments.
