# v036-multiple-sprites

Open `Line Rider.sb3` in Scratch. `source/native/project.json` contains the exact executable Scratch blocks, variables, lists and costume metadata. All assets are beside it. Run `python rebuild.py` to repack them as `rebuilt.sb3`.

The complete Python generator and its dependencies are preserved under `source/generator`. Run `python tools/build.py` from that directory to regenerate the project.
